# 農科院環安小組看板｜測試原型

財團法人農業科技研究院「環安小組」靜態測試看板（zh-Hant-TW）。純靜態檔案，無需建置步驟。

## 如何開啟

請使用本機 HTTP 伺服器（`fetch` 載入 JSON，不建議直接用 `file://`）：

```bash
cd /workspace/ehs-dashboard
python3 -m http.server 8765
```

瀏覽器開啟：<http://127.0.0.1:8765>

## 檔案結構

| 路徑 | 說明 |
|------|------|
| `index.html` | 頁面結構 |
| `styles.css` | 樣式（青綠專業實驗室風格） |
| `app.js` | 渲染與客戶端問答 |
| `data/dashboard.json` | **全部內容資料來源** |
| `README.md` | 本說明 |

## 看板區塊

1. 頁首：農科院環安小組看板｜測試原型｜更新日期（臺北）
2. 人員編制與職稱
3. 各場域證書與效期（矩陣＋圖例：有效／NA／—）
4. 近期待辦與限期（常設規則＋日曆項）
5. 近期重點異動法規
6. 側邊／固定提問面板：「測試、構思執行者」

## 場域名稱（嚴格）

僅使用：**正育牧場**、**竹南院區**、**香山院本部**、**香山SPF**。  
請勿寫成「香山院區」。

## 提問面板限制（聊天）

- **僅客戶端**：依嵌入／載入的 `dashboard.json` 回答，**無外部 LLM、無 API Key**。
- 答案為繁體中文；資料不足時回覆：  
  `看板無此資料，請至 Grok Bot 找「測試、構思執行者」確認。`
- 建議快捷問題：正育水污效期？／竹南誰負責消防？／下次廢污水申報窗口？
- 對話紀錄可選存於瀏覽器 `localStorage`（本機、非正式歸檔）。

## 注意事項

- 本看板為**測試用途**；正式對外／正式歸檔仍走原窗口＋審稿門檻。
- 人員與證書資料來源於 115 年度名單／權限表與已知窗口，請持續核對。
